# About the Weather Provider Libraries and API project

## History

The Weather Provider Libraries and API project — originally known simply as the *Weather Provider API* — was conceived
between 2018 and 2019 with the goal of providing a standardized interface for accessing weather data from multiple
sources. This work culminated in the release of both the initial prototype and version 1.0 of the API in 2019.

With the completion of version 2.0 in 2024, the project matured into a fully-fledged library and API capable of
accessing weather data from a wide variety of sources. This milestone also marked the project's transition to open
source in 2025.

The project is currently maintained by a small team of developers and contributors, who continue to extend and improve
its functionality.
